# Бавар+ · Прототипы калькулятора экономии

Четыре концепта блока «Калькулятор экономии» (блок 7 ТЗ) для согласования формата с клиентом.

## Как смотреть

Откройте `index.html` в браузере — оттуда ссылки на все четыре прототипа. Никаких сборок не нужно, всё работает локально из файлов.

## Прототипы

| # | Файл | Идея | Кому показать |
|---|------|------|---------------|
| 01 | `prototype-1.html` | Три слайдера — состав отдела, оклад, сделки. Мгновенный пересчёт. | Тем, кто хочет «потрогать» сам |
| 02 | `prototype-2.html` | Пошаговый wizard — 3 шага, большие кнопки, итоговый экран. | Низкий порог входа, B2C-логика |
| 03 | `prototype-3.html` | Пресеты «малое / среднее / крупное» + подкрутка значений. | Самый быстрый — клик и видна экономия |
| 04 | `prototype-4.html` | Таблица со статьями расходов, сравнение с тремя тарифами. | Финдиректора, отделы закупок |

## Базовая модель расчёта

Одинаковая во всех прототипах, разная подача:

- **Свой отдел ВЭД** = ФОТ + страховые взносы (≈30%) + рабочие места + ПО + командировки в Китай + резерв на риски
- **Бавар+** — фикс по тарифу (Лайт 300к / Стандарт 500к / Максимум 800к ₽/мес)
- **Экономия** = Свой отдел − Бавар+

## Что цифры демонстрационные

Перед запуском нужно зафиксировать:
- Финальные тарифы Бавар+ и что в них входит
- Типовой состав штатного отдела ВЭД (сейчас в `assets/format.js`)
- Размер взносов (УСН/ОСН влияет на ставку)

## Структура

```
Bavarplus/
├─ index.html              ← главная со списком прототипов
├─ prototype-1.html        ← слайдеры
├─ prototype-2.html        ← wizard
├─ prototype-3.html        ← пресеты
├─ prototype-4.html        ← детальный
└─ assets/
   ├─ styles.css           ← общий минималистичный стиль
   └─ format.js            ← форматирование чисел, тарифы, типовой отдел ВЭД
```
